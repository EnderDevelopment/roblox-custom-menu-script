# Customizable Menu Script for Roblox

This project provides a customizable menu script for Roblox games, featuring interactive buttons for rounds 1 and 3, and a size customization tool. The script is designed to be easily integrated into Roblox Studio, allowing players to navigate through game rounds and adjust their character size with simple clicks.

## Install

1. Download the script files from the GitHub repository.
2. Open your Roblox game in Roblox Studio.
3. Navigate to the `StarterPlayerScripts` folder.
4. Drag and drop the `Round1Script.lua` and `Round3Script.lua` files into the `StarterPlayerScripts` folder.
5. Navigate to the `StarterGui` folder.
6. Drag and drop the `MenuScript.lua` file into the `StarterGui` folder.
7. Drag and drop the `SizeCustomizationScript.lua` file into the `StarterPlayerScripts` folder.

## Use

1. Start the Roblox game.
2. The menu will appear with buttons for Round 1 and Round 3.
3. Click on the desired round button to start the respective round.
4. Use the size customization tool to adjust your character size by clicking the size slider button.
